# AnTi — 纯本地 AI Agent 桌面助手

> 一个完全运行在你自己电脑上的 AI Agent 桌面软件。基于本地 Ollama 模型驱动，支持文件访问、命令执行、键鼠外设控制与视觉截图，并以单文件自包含安装包（`AnTi-Setup.exe`）分发，双击即装、全程离线、无需联网。

---

## 这是什么

AnTi 是一个用 Python + tkinter 写的轻量桌面 Agent。它直接调用你本机运行的 **Ollama** 本地大模型（默认 `deepseek-coder:1.3b`，视觉/执行场景建议 `qwen3-vl:2b`），把模型变成能「动手」的助手：读文件、跑命令、控制鼠标键盘、看屏幕截图，并在多模型协作下给出答案。

所有能力都通过「开关」单独控制——不需要联网、不上传任何数据，一切都在本机完成。

---

## 功能提示词 / 需求清单（原始设计目标）

下面是本项目逐版迭代时沉淀下来的核心诉求，也是本仓库所实现的能力：

1. **本地模型驱动**：模型跑在电脑本地，通过 Ollama（默认地址 `http://localhost:11434`），端口/模型名可自行配置；小型软件形态，打开只有常规模型参数与聊天框，类似 Codex 的简洁界面。
2. **可自动化操控**：纯本地运行，具备自动化执行能力；参考 Codex 的 Agent 形态，不只是聊天，而是能真正去「做」。
3. **访问全部文件开关**：提供「访问全部文件」总开关，开启后即全接管本机文件系统（高危命令进入黑名单拦截，避免误删/破坏）。
4. **可部署 Skill**：支持把可复用能力以 Skill 形式接入并部署，让 Agent 越用越强。
5. **多模型协作**：支持主模型 + 最多 2 个协助模型协同；可手动勾选哪两个协助模型参与，或由主模型统一调度。
6. **个人聊天 / Agent 双模式切换**：个人聊天模式下不开启 Agent，不跑自动化流程；只有手动切到 Agent 模式才执行自动化。个人聊天模式同样可接入多模型回答。
7. **主模型 + 协助模型 + 右侧独立窗口**：Agent 模式下，协助模型先各自给出精简回答，显示在**右侧独立窗口**；完成后由主模型根据协助模型的归纳结果总结并执行输出。
8. **视觉功能开关**：独立开关。开启后可让视觉模型「看」屏幕——后台自动截图并喂给视觉模型，也支持手动上传图片（手动上传优先级高于自动截图）。
9. **外设控制开关**：独立开关，接入键鼠外设控制（鼠标移动/点击/双击/右键/拖拽/滚轮、键盘输入/组合键），由 Agent 通过工具协议调用。
10. **单文件自包含安装包**：打包为单个 `AnTi-Setup.exe`，运行后从自身内嵌资源释放 `AnTi.exe` 本体到本地（`%LOCALAPPDATA%\AnTi`），并自动建立桌面与开始菜单快捷方式，无需同目录附带其他文件。

## 安装

1. 下载本仓库根目录的 **`AnTi-Setup.exe`**（单个文件，约 31 MB，已内嵌本体与图标）。
2. 双击运行 → 选择安装位置 → 点「安装」。
3. 安装完成后，桌面和开始菜单都会出现 `AnTi` 快捷方式，点击即可启动。

> 安装与运行全程纯本地、无需联网。

---

## 使用前提

- 本机需安装并运行 **Ollama**：
  - 启动：`ollama serve`（Ollama 默认不会随系统自启，首次使用请先启动）。
  - 拉取模型：`ollama pull deepseek-coder:1.3b`（默认）；视觉/执行场景建议 `ollama pull qwen3-vl:2b`。
- 在软件内通过「模型参数」面板确认 Ollama 地址（默认 `http://localhost:11434`）与模型名。

---

## 安全说明

- **「访问全部文件」为高危开关**，开启后 Agent 可读写本机任意文件；软件内置危险命令黑名单（如 `rm -rf /`、格式化等）进行拦截。
- **外设控制**（键鼠）默认关闭，且 `pyautogui` 启用了 FAILSAFE（把鼠标甩到屏幕左上角即可紧急中止）。
- 所有数据不出本机；不使用任何云端 API。

## 源码结构

| 文件 | 说明 |
| --- | --- |
| `agent_chat.py` | 主程序（约 1200 行）：聊天 UI、流式输出、工具调用协议、多模型协作、视觉/外设控制、配置持久化。 |
| `installer.py` | 安装程序源码：从自身内嵌资源释放 `AnTi.exe` 并建立快捷方式。 |
| `setup.spec` | PyInstaller 打包配置（把 `AnTi.exe` 与图标打进安装包，输出 `AnTi-Setup.exe`）。 |
| `AnTi.spec` | 主程序 PyInstaller 打包配置。 |
| `assets/` | 圆角应用图标（`anti_icon.ico` / `.png` / `.jpg`）。 |
| `deploy_setup.py` | 本地部署辅助脚本（复制到桌面）。 |
| `AnTi-Setup.exe` | 最终交付的单文件自包含安装包。 |

## 构建（供开发者）

```bash
# 1) 打包主程序本体
pyinstaller --onefile --noconsole --name "AnTi" --icon assets/anti_icon.ico \
  --add-data "assets;assets" --hidden-import pyautogui --hidden-import PIL \
  --hidden-import PIL.Image --hidden-import PIL.ImageGrab agent_chat.py

# 2) 把生成的 dist/AnTi.exe 放到本目录，再打包安装程序
pyinstaller --noconfirm setup.spec
# 产物：dist/AnTi-Setup.exe（自含本体）
```

> 构建环境需 Python 3.13 + PyInstaller + pywin32 + pyautogui + Pillow。
